# Website Structure & UI/UX Rules

## 🗺️ Sitemap
- `/` (Home): Value proposition, routing to crops/problems.
- `/giai-phap/[slug]`: Solution Pages (The core educational funnel).
- `/san-pham/[slug]`: Product Detail Pages (Specs, usage, mobile-optimized).
- `/kien-thuc`: Blog/Knowledge Base.
- `/admin` & Seller Portal: Extreme simplicity.

## 📱 UI/UX Core Rules (Mobile-First)
- **Buttons**: Minimum height 44px (Thumb-friendly).
- **Navigation**: Clean, sticky header, max 2 levels deep, prioritize icons.
- **CTAs**: Bright, high-contrast, always visible (Sticky bottom bar on mobile).
- **Product Display**: Large clear images, highly visible pricing, immediate social proof/reviews.

## ⚙️ Core Features
- Knowledge-driven marketplace.
- Content hubs (Solution pages).
- Simplified Seller Dashboard.
- Shopping cart & checkout (Secondary to direct consultation).
