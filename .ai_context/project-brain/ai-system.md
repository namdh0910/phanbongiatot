# Persistent AI Memory & Skills System

This architecture ensures the AI assistant maintains context and follows project rules consistently.

## 🎯 Core Project Focus (New)
- **Model**: Drop-shipping Niche (Agricultural products).
- **Hero Products**: Nemano (Nematode treatment) and Plant Recovery Solutions (Bộ phục hồi cây).
- **Content Strategy**: All future content, features, and optimizations must revolve around this "Solution-First" niche model.
- **Conversion**: Prioritize Zalo/Phone chốt đơn trực tiếp over traditional e-commerce checkout.

## 🧠 Memory Structure (`/.ai_context/memory`)
- `recent-memory.md`: Tracks tasks from the last 48 hours.
- `long-term-memory.md`: Core philosophy (Solution-based selling) and project rules.
- `project-memory.md`: Current technical state and architecture.

## 🛠️ Skills Structure (`/.ai_context/skills`)
Reusable logic modules the AI applies to specific tasks:
- `build-solution-page.md`: Template for high-converting content.
- `write-agri-content.md`: "Happy Agri" copywriting guidelines.
- `cro-audit.md`: Conversion rate optimization checklist.
- `seo-structure.md`: SEO rules for agricultural queries.
- `system-thinking.md`: Ensures outputs align with the core business model.

## 🔄 Workflow Loop
1. Analyze user request.
2. Load Memory + Project Brain.
3. Select relevant Skill.
4. Execute and run System-Thinking audit.
5. Update `recent-memory.md`.
