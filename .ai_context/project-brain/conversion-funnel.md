# Conversion Funnel & User Flows

## 🌪️ The Buyer Journey (Solution-Based Funnel)
1. **Awareness (Top)**: User discovers content via TikTok, YouTube, or Google Search.
2. **Consideration (Middle)**: User lands on a Solution Page or Blog. They read empathetic, practical advice that accurately diagnoses their crop's problem.
3. **Conversion (Bottom)**: User clicks the Sticky Zalo/Phone CTA. Traditional checkout is secondary. The goal is a consultation message: "My durian is dropping leaves, what should I use?"

## 🔄 Seller Flow
1. Register -> 2. Upload Product (1 simple form) -> 3. Receive Order -> 4. Process.
- **Focus**: Minimum friction. Must be manageable entirely via mobile.

## 🚧 Known Friction Points
- Losing buyers between "Viewing Product" and "Buying" -> Solved by shifting focus from "Add to Cart" to "Consult via Zalo".
- Seller dashboard complexity -> Solved by extreme simplification.
