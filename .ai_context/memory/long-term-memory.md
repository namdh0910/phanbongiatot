# Long-Term Memory

## 🎯 Project Identity
- **Name**: phanbongiatot.com
- **Core Philosophy**: Sell SOLUTIONS, not just products.
- **Target Audience**: Vietnamese farmers (focus on durian, coffee, pepper).
- **Primary Conversion Metric**: Direct consultation requests via Zalo/Phone.

## 🧠 Distilled Knowledge
- **UX/UI**: Must be mobile-first, thumb-friendly, with high-contrast text for outdoor readability. Fast loading is essential.
- **Content**: Should follow the "Happy Agri style" - practical, empathetic, real-world examples, no fluff.
- **Conversion**: Traditional e-commerce checkout is secondary. The main goal of any page is to build trust and get the farmer to call or message for advice.
- **SEO**: Focus on problem-solution keyword pairs (e.g., "sầu riêng vàng lá thối rễ", "cách trị rệp sáp").
