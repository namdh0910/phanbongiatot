# Skill: CRO Audit (Conversion Rate Optimization)

## 🎯 Purpose
Evaluate a page to ensure it maximizes the chance of a user taking the desired action (messaging Zalo/Calling).

## 📥 Input
- URL or Page Component code.
- Target audience intent for that page.

## 📤 Output
- A prioritized checklist of improvements.

## 📋 Steps
1. **Above the Fold**: Is the main value proposition clear within 3 seconds? Is there a visible CTA?
2. **Friction Points**: Are there too many steps to contact? Is the phone number clickable (`tel:`).
3. **Trust Signals**: Are there real photos, reviews, or guarantees visible near the CTA?
4. **Mobile Check**: Are buttons thumb-friendly (min 44px height)? Is text readable without zooming?
5. **Clarity over Cleverness**: Is the copy straightforward? Does it tell the user exactly what will happen when they click?

## 💡 Example
**Audit Finding**: "Nút 'Thêm vào giỏ' to hơn nút 'Tư vấn Zalo' trên trang trị bệnh."
**Recommendation**: "Ẩn nút 'Thêm vào giỏ', làm nổi bật nút 'Tư vấn Zalo' vì khách hàng cần hỏi kỹ thuật trước khi mua thuốc bệnh."
