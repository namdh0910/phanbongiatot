# Skill: SEO Structure for Agriculture

## 🎯 Purpose
Structure content to rank high on Google for long-tail, problem-solving agricultural keywords.

## 📥 Input
- Primary keyword (e.g., "phân bón sầu riêng").
- Secondary keywords.

## 📤 Output
- An SEO-optimized document outline and meta tags.

## 📋 Steps
1. **URL Slug**: Short, keyword-rich (e.g., `phan-bon-sau-rieng-giai-doan-nuoi-trai`).
2. **Meta Title**: Keyword + Compelling hook + Brand (e.g., "Cách bón phân sầu riêng nuôi trái lớn nhanh, không sượng | Phân Bón Giá Tốt").
3. **Meta Description**: Problem + Solution + CTA (under 160 chars).
4. **Headings**: 
   - H1: Only one, contains primary keyword.
   - H2: Main sections (questions farmers ask).
   - H3: Specific steps or product mentions.
5. **Internal Linking**: Link to specific product pages using exact anchor text. Link to related disease articles.

## 💡 Example
**H1**: Sầu riêng rụng trái non: Nguyên nhân và cách khắc phục triệt để
**H2**: Tại sao sầu riêng rụng trái non?
**H3**: Sốc nước do mưa trái mùa
**H3**: Cạnh tranh dinh dưỡng (đi đọt)
**H2**: Cách chặn đọt sầu riêng an toàn
**H2**: Phác đồ chống rụng trái từ kỹ sư Phân Bón Giá Tốt
