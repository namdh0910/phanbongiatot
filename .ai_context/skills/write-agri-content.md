# Skill: Write Agri Content (Happy Agri Style)

## 🎯 Purpose
Write content that resonates deeply with Vietnamese farmers—simple, practical, empathetic, and highly actionable.

## 📥 Input
- Topic or keyword.
- Target crop.
- Goal of the article.

## 📤 Output
- A well-structured article (1000 - 3000 words) formatted for easy reading.

## 📋 Steps
1. **Tone Check**: Use terms like "Bà con", "Nhà vườn". Avoid overly academic jargon unless explained immediately with an analogy.
2. **Structure**: 
   - H1: Keyword + Benefit.
   - Intro: Empathize with the pain point.
   - Body: Use bullet points, bold text for skimming.
   - Analogies: Relate biological processes to everyday things (e.g., "rễ cây như cái miệng").
3. **Formatting**: Break text into short paragraphs. Use emojis sparingly but effectively (🌱, ⚠️, 👉).
4. **Actionable Takeaways**: Always end with a clear "Việc cần làm ngay".

## 💡 Example
**Instead of**: "Sản phẩm chứa hàm lượng lân hữu hiệu cao giúp kích thích hệ rễ phát triển."
**Write**: "Lân trong chai này ở dạng dễ tiêu, cây hấp thu được ngay. Rễ bung mạnh, trắng xóa như giá đỗ, giúp cây ăn phân tốt hơn."
