# Skill: System Thinking & Alignment

## 🎯 Purpose
Ensure every piece of code, content, or UI element aligns with the core business strategy: Solution-Based Selling.

## 📥 Input
- Any proposed feature, design change, or content draft.

## 📤 Output
- A GO/NO-GO decision with alignment feedback.

## 📋 Steps
1. **The 'Why' Test**: Why are we adding this? Does it help the farmer solve a problem or does it just look cool?
2. **The Conversion Test**: Does this feature drive the user closer to a Zalo/Phone consultation?
3. **The Complexity Test**: Is this too complex for a farmer to use on a cheap Android phone out in the field?
4. **The Maintenance Test**: Can the admin easily update this without touching code?

## 💡 Example
**Proposal**: "Let's add a 3D product viewer."
**System Thinking**: "NO. Farmers don't care about a 3D model of a bottle. They care about what's inside and if it cures their yellow leaves. Spend that development time making the 'Solution Page' load 1 second faster on 3G."
