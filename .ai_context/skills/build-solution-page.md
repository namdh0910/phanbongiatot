# Skill: Build Solution Page

## 🎯 Purpose
Create a high-converting, problem-focused landing page that educates the user and drives them to contact for consultation.

## 📥 Input
- Crop type (e.g., Sầu riêng, Cà phê)
- Specific problem (e.g., Vàng lá thối rễ, Rệp sáp)
- Relevant products for the solution

## 📤 Output
- A structured HTML/React component or Markdown content following the solution-based template.

## 📋 Steps
1. **Hook**: Start with a relatable scenario or pain point the farmer is facing.
2. **Diagnosis**: Explain *why* the problem is happening in simple terms.
3. **The Solution (Method)**: Outline a step-by-step method to solve the problem (don't just pitch products immediately).
4. **Product Integration**: Introduce the specific product(s) as the tool to execute the solution. Explain the *mechanism*.
5. **Social Proof**: Add testimonials or real-world results.
6. **CTA**: Prominent Sticky CTA to Zalo or Phone for personalized advice.

## 💡 Example
**Hook**: "Sầu riêng đang mang trái mà rụng lá hàng loạt? Khoan vội bón phân!"
**Diagnosis**: "Nguyên nhân chính là do nấm Phytophthora tấn công rễ..."
**Solution**: "Bước 1: Cắt nước. Bước 2: Xử lý nấm. Bước 3: Phục hồi rễ."
**Product**: "Dùng bộ đôi Acti Rooti + Nemano để trị nấm và kích rễ..."
**CTA**: "👉 Chụp ảnh gốc sầu riêng gửi Zalo [Số ĐT] để kỹ sư tư vấn phác đồ miễn phí!"
